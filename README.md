# 牌友斗地主 · uni-app 版（离线单机演示）

基于 `../doudizhu-model-comparison` 原版网页斗地主重构：抽出**无 DOM 依赖的游戏引擎**，按 uni-app（Vue 3）规范重写界面，可打包为 **H5 网页 / Android & iOS App / 微信小程序**。

> ⚠️ 演示声明：离线单机，无真实支付、无银行绑定、不收集任何信息。「充值」仅在本机模拟成功；金币与积分只保存在本机。

## 功能

- **完整牌局**：发牌（逐张飞入动画）→ 叫地主（1/2/3 分，AI 会叫分，三轮流局随机指定地主）→ 加倍（地主可 ×4，全员表态）→ 出牌 → 结算（底分 × 加倍 × 2^炸弹数 × 春天×2）。
- **春天/反春**：地主赢且农民一张未出（春天）或地主只出过一手即输（反春）时分数翻倍，结算面板会标注。
- **结算界面**：全屏面板显示胜负横幅、完整计分公式、三家角色与分数变化（+绿/-红）、剩牌数，支持「看牌桌」/「再来一局」。
- **横屏优先**：App 默认横屏（`manifest.json` screenOrientation），竖屏窄屏显示「横屏体验更佳」提示；布局对齐竞品——两个对手在桌面两上角、底牌与倍数居中、手牌底部单行堆叠（露出点数+花色角标，点击上移选中）。
- **逐座位出牌展示**：每个对手最近出的牌（或「不出」）显示在其座位旁，新一圈开始自动清空。
- **托管**：顶栏「托管」按钮，AI 替你叫分/加倍/出牌，可随时取消；手动操作不受影响。
- **本地账户系统**：注册/登录/退出/游客模式，密码加盐 SHA-256 哈希仅存本机；每个账户的积分、战绩、钱包、偏好完全隔离；未登录自动跳转账户页；首个注册账户自动迁移旧版单机数据；设置页可退出或切换账户。
- **AI 等级**：初级/中级/高级三套出牌逻辑——初级乱出（不认队友、爱拆牌）、中级默认策略（配合队友、压制地主）、高级留牌后出（先甩散牌、不拆炸弹应牌、思考时间更长）。每局两位 AI 等级随机且互不相同，座位旁有「初/中/高」徽章。
- **每局随机 AI**：AI 名字/emoji 头像/底色每局随机抽取，不重复。
- **表情互动**：牌桌顶栏 😉 打开表情面板发送，AI 出牌后有概率回应表情。
- **自定义外观**：牌背在青竹/朱雀之外支持自定义（emoji 图案 + 底色，实时预览），我的头像同样支持 emoji + 底色，设置页即可修改。
- **提示反馈**：能压过时自动选牌并提示确认；压不过时内联提示「点不出过牌」，不再无反馈。
- **选牌牌型识别**：选中手牌即时显示牌型（如「4 对」「顺子」），不成牌型红字提示。
- **记牌器**：顶部实时统计未知牌（54 − 我的手牌 − 已打出 − 已亮底牌），点击可收起/展开。
- **音效**：WebAudio 合成发牌/出牌/炸弹/胜负音（无外部资源），设置页可关。
- **出牌倒计时**：轮到玩家 20 秒倒计时，超时自动行动（不抢/不加倍/自动出牌或不出），竞品防挂机行为。
- **明牌模式**：设置页开启后 AI 手牌正面展示（练习用）。
- **积分系统**：每局结算积分（地主 ±2 倍），累计战绩在牌桌顶栏与设置页查看。
- **金币钱包（模拟支付）**：初始 12,000 演示金币；¥1/¥6/¥30/¥68/¥128 档位（¥1=100 金币）模拟充值、交易记录、清空记录；金币不参与对局输赢。
- **个性化**：桌面背景三款（青竹绿/深海蓝/暗夜紫）+ 牌背两款（青竹/朱雀），设置页切换、本机保存。
- **牌型**：单张/对子/三张/三带一/三带二/顺子(≥5)/连对/飞机(带单带对)/炸弹/王炸；不支持 4 带 2。
- **提示**：跟牌给最小可压组合，领出给成牌/低顺/低对/低三带。

## 相对原版修复的问题

| # | 问题 | 修复 |
|---|------|------|
| 1 | 起叫者是 AI 时叫地主永久卡死 | 开局后为 AI 调度首步行动 |
| 2 | 卡死后无「重新发牌」可用 | 重开按钮常驻顶栏（带确认） |
| 3 | 加倍轮按 `p===2` 判断，漏过玩家 | 三家全部表态后才进入出牌 |
| 4 | 流局计数被重发清零，随机地主永远触发不了 | 计数保存在对局实例上 |
| 5 | AI 领出只会甩最小单张 | 领出依次尝试整手成牌→低顺→低对→低三带→散牌 |
| 6 | 多炸弹只翻一倍 | `bombCount` 按次数 ×2 叠加 |
| 7 | 应三带一时手牌缺该点数即崩溃（`by[r]?.length < 3` 判断失效） | 改为显式判空；50 局全随机托管压力测试零崩溃 |
| 8 | 明牌模式干扰叫分逻辑 | 明牌仅影响展示 |
| 9 | 「地主获胜」统计实为玩家胜局 | 文案与口径统一为玩家战绩 |

## 后端与部署

### 首次部署须知

- `backend/data/` 为运行时数据目录（账号/对局/上传素材），**服务器首次启动自动生成**，请勿提交到仓库（已加入 .gitignore）。
- 部署后自检：`python3 backend/smoke_test.py`（25 项 API 验收）。

### 启动后端（Python 标准库，零依赖）

```sh
python3 backend/server.py 8080
# 管理面板: http://localhost:8080/admin   官网: http://localhost:8080/
# 管理员密码: 环境变量 DDZ_ADMIN_PWD（默认 admin123）
```

### 数据库三选一（环境变量）

| 方式 | 配置 | 说明 |
|------|------|------|
| JSON（默认） | 无 | `backend/data/db.json`，零配置 |
| SQLite（本地 SQL 文件） | `DDZ_DB=sqlite`（可选 `DDZ_SQLITE_PATH`） | 生成 `backend/data/ddz.sqlite`，表结构见 `backend/schema.sql`，可用 sqlite3 等工具直接查看/注入 |
| MySQL / PostgreSQL | `DDZ_DB_URL=mysql://user:pwd@host:3306/db` 或 `postgres://...` | 需 `pip install pymysql` / `psycopg2-binary`；建表执行 `schema.sql` |

SQL 备份/迁移：
```sh
python3 backend/server.py --export-sql dump.sql   # 导出全部数据为 SQL
python3 backend/server.py --import-sql dump.sql   # 导入（也可用管理面板 /api/admin/import）
```
管理员 API：`GET /api/admin/accounts|export?format=sql|json`、`POST /api/admin/recharge|points|delete|import|sql`（请求头 `X-Admin`）。

### 后台管理面板（/admin）

- **运营看板**：注册玩家数（今日+）、今日活跃、7 日活跃、当前在线、客户端安装量（按 App/网页版平台分组，今日+）、累计对局，近 7 天柱状图。
- **账户管理**：金币/积分/局数/胜场/签到/记录条数一览；充值金币、调整积分、查看对战记录、销号。

### 联机对战

- **随机匹配**：进入玩家队列，凑满 3 人立即开局；等待 30 秒仍不足则自动补 AI。
- **好友对战**：房主建房（6 位房号）→ 好友加入（最多 3 人）→ 房主开局自动补 AI → 支持观战（观战者输入房号即可）。
- **断线重连**：重新登录进入联机大厅自动回到进行中对局；连续 3 个心跳周期（约 15 秒）无心跳判定离线，AI 托管接管，重连后恢复人类操作。
- 对局由服务端权威推进（Python 移植的规则引擎 + AI），客户端仅发送操作并轮询状态。

### 客户端接入联机

设置页 →「服务器地址」填 `http://host:8080` → 保存 → 点「联机对战」。账户走服务器注册/登录（或游客），签到 +2000 积分/天，充值弹支付宝/微信二维码（演示流程，点击"已完成充值"即到账），对战记录从服务器拉取（保留 1 个月内最多 30 条展示）。

### 网页版官网

`http://host:8080/` 提供参照欢乐斗地主官网设计的手游官网（全屏 hero 动画、新闻公告面板、截图墙、多端下载矩阵、客服支持），内置中英文切换、移动端汉堡菜单自适应；网页版访问按 `platform=web` 计入安装量统计。将 uni-app 发行 H5 的产物放到 `backend/web/h5/` 即可实现"网页版直接玩"。

### 公告 / 下载 / 素材管理（管理面板）

- **公告管理**：发布/编辑/删除公告（分类：最新/新闻/公告/活动），官网新闻面板实时联动。
- **下载管理**：各平台（Android/iOS/Windows/网页版…）的名称、说明、链接、图标可增删改，官网下载矩阵实时生效。
- **图案素材库**：玩家登录后可上传头像/牌背图片（`POST /api/upload`，base64 ≤512KB，存 `backend/data/uploads/`），管理面板可查看与删除，文件经 `/uploads/<id>` 访问。

### 客户端多端打包

`manifest.json` 已配置 App 默认横屏。HBuilderX：发行 → 原生 App-云打包（Android 用公共证书；iOS 需开发者账号）。官网下载按钮指向 `/download/android.apk`（替换为真实 APK）与 `/download/ios`（替换为 App Store 链接）。

## 用 HBuilderX 打包成 App

1. HBuilderX → 文件 → 导入 → 从本地目录导入 → 选择本目录。
2. **运行**：运行 → 运行到浏览器（H5 调试）；或运行到手机/模拟器（真机调试）。
3. **发布 H5**：发行 → 网站-PC Web或手机H5 → 产物在 `unpackage/dist/build/h5`，任意静态服务器可托管。
4. **打包 App**：
   - 发行 → 原生App-云打包；Android 无需证书可直接使用公共测试证书，iOS 需要开发者账号与证书。
   - `manifest.json` 里已声明 VIBRATE 权限（炸弹/结算震动）；未启用推送/地图等任何三方 SDK。
5. **微信小程序**（可选）：发行 → 小程序-微信，填入自己的 AppID（`manifest.json` → `mp-weixin`）后用微信开发者工具打开。

## 数据与隐私

- 全部数据存于本机 storage（键 `ddz-profile-v1`）：金币、交易记录、昵称、偏好、战绩。
- 不发起任何非自身静态资源的网络请求；设置页可一键重置（金币恢复 12,000）。
